Material Design emphasizes adaptable systems, clear hierarchy, purposeful motion, and components that behave predictably. Interfaces should use shape, color, typography, and elevation consistently so users can understand relationships and available actions.

Generated UI components should expose semantic variants, strong state feedback, accessible labels, and consistent spacing. Components should be reusable and configurable without hiding core behavior.
